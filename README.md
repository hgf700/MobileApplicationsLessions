**Mobile Applications Lessons**

Technologies Used:

Backend: Python (Flask)

Frontend: HTML, CSS, JavaScript

Database: PostgreSQL with migrations

Architecture: Blueprints / Controllers to separate application logic

Security: HTTPS local certificates, JWT

Middleware: Redirects users to the login view if a JWT does not exist or the user is not logged in

Map View: Leaflet, Leaflet routing

Audio Generation: gTTS (Google Text-to-Speech)
